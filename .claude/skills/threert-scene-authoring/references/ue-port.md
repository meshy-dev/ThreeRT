# Porting an Unreal level (ground-truth loop)

Use this when a UE project already has the look you want, as with the UE 5.8 Kabukichō session. The target is the UE
level as UE renders it, from fixed cameras. Don't aim at a UE render of your own approximation: per-feature parity
does not converge on the content's look. Work on a scratch copy of the UE project (`cp -R`); the capture script saves
the level.

## 1. Ground truth

```bash
# level dump: actors, transforms, meshes, material-instance params, lights, fog, post overrides, sky light
THREERT_DUMP='{"map": "/Game/X/Maps/L_X", "out": "/abs/level.json"}' \
  UnrealEditor <scratch>.uproject -ExecCmds="py ue5/scripts/ue_dump_level.py" -unattended -nosplash -NoSound
# MRQ stills (add the MovieRenderPipeline plugin to the scratch .uproject first)
bun ue5/capture.ts <scratch>.uproject job.json
```

`job.json`:

```json
{"map": "/Game/X/Maps/L_X", "out": "/abs/dir", "method": "lumen", "width": 1280, "height": 720,
 "views": [{"name": "v1", "location": [x, y, z], "rotation": [pitch, yaw, roll], "fov": 55}],
 "hide": ["CrowdActorClass"], "ev100": null, "linear": false, "cvars": {}}
```

Make two captures:

- **Display**: `ev100: null`, the authored auto exposure, PNG. This is the acceptance image.
- **Radiometric**: `ev100: 1.5, linear: true`. It writes an EXR with the tone curve, bloom and local exposure off.

Pick 4–6 views covering eye level, an overview and the hero spots. Hide particle rain and crowds; they never match
frame to frame. Use `cvars: {}` when the project uses software Lumen (check its DefaultEngine.ini).

## 2. Port the content, not the look

- If the level was generated by a script, port the script line by line. `PyRandom` (`@threert/scene`) is CPython's
  `random.Random`, so the same seed gives the same layout. Vendor any texture generators unchanged and run them with
  `python -I`.
- Coordinates: UE (x, y, z) cm, Z up → ours (x/100, z/100, y/100). For rotation use R = P·R_ue·P with P swapping y/z,
  scale (sx, sz, sy). Lights and cameras need an extra −90° about y.
- Master materials become `MaterialFunction`s ([MATERIAL_FUNCTIONS.md](../../../../docs/MATERIAL_FUNCTIONS.md)). Copy
  the HLSL math, keep the parameter names, and evaluate hashes and world mapping in UE space (`ue_pos(i.wp)`,
  `ue_pos(i.op)`) so the patterns match.
- Lights: rect lights use `RectAreaLight(color, cd / (w·h), w, h)` with `card = false` (UE rect lights are invisible
  to the camera), `distance` = attenuation radius / 100 and `barnDoorAngle`. Carry over `volumetricScattering` and
  `specularScale`. `unreal.Color(r, g, b)` stores B, G, R: reproduce what UE renders.
- Fog: `ExponentialHeightFog.fromUnreal({...})` takes the component's raw values.
- Post: copy the PostProcessVolume overrides (bloom, exposure, local exposure, grading). Check
  `r.DefaultFeature.AutoExposure.ExtendDefaultLuminanceRange`: without it the min / max brightness are luminances,
  not EV100 (use EV = log2(value)).
- Verify the port actor by actor against the dump before looking at any image (compare positions, scales, rotations
  and material assignments; e.g. `node tools/kabukicho/dump-street.ts > ours.json && python3
  tools/kabukicho/verify-port.py level.json ours.json`).

## 3. Converge

```bash
python3 tools/kabukicho/views.py out/bundles/x.js out/x-views 55 --spp 256   # v1..v6.png at the UE cameras
renderer/target/release/threert-render compare ue/v1.png out/x-views/v1.png   # display ΔE / SSIM / luminance ratio
renderer/target/release/threert-render render out/bundles/x.js -o v1.png --camera '{"position":[..],"target":[..],"fov":55}' --hdr v1.raw
renderer/target/release/threert-render compare-hdr ue-linear/v1.exr v1.raw 1.5 --heat heat.png   # radiometric
```

Fix things in order: geometry and port bugs first (they show up in the heat map as shapes), then radiometry (fix
luminance-ratio outliers per view by checking light units and exposure), then display (exposure, bloom, grade). Record
the metrics per iteration. Do not tune per scene: every fix should be a generic engine change, or a faithful
translation of a UE setting.

Typical findings: exposure semantics (auto-exposure ranges, local exposure), unit conversions (fog density / falloff
per cm, base 2), light units (rect cd vs nits), invisible-to-camera lights, sky material details (gradient exponent,
glow band), and sign text washed out live (the denoiser; directly seen emission now bypasses it).
