ThreeRT

Three, for the API you already know. RT, for the three things it adds.

  1. Ray Tracing

    Every light is traced: shadows, bounce light, reflections and glowing surfaces that light the room. No shadow maps, no light probes, no baking.

  2. Real Time

    60 fps in production scenes, with the camera moving. Not a still that converges once you stop.

  3. Runtime

    A game runtime, not only a renderer. Scene code and game logic run inside the engine, and the same scene runs as three.js in any browser.
