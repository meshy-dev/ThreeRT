ThreeRT

Three, for the API you already know. RT, for the three things it adds.

  1. Ray Tracing

    Every light is traced: shadows, bounce light, reflections and glowing surfaces that light the room. No shadow maps, no light probes, no baking.

  2. Real Time

    60 fps in production scenes, with the camera moving. Not a still that converges once you stop.

  3. Runtime

    A game runtime, not only a renderer. Scene code and game logic run inside the engine, and the same scene runs as three.js in any browser.

One command
puts yours online.

      
Publishing gives a project an address, a page in the catalogue and a package ThreeRT opens directly. It needs a GitHub account and nothing else.

    

    
    
      
  1. Write three.js-style code
    A scene is a TypeScript module against @threert/scene: meshes, MeshStandardMaterial, lights, glTF models. The light is traced, not configured.
    
        
    const ball = new Mesh(sphere, gold);
ball.position.set(0, 0.42, 0);
scene.add(ball);
return { scene, camera };
    2. 
      
  2. Run threert publish
    In the project’s directory. It packs the project, takes a cover from ThreeRT, uploads the files that changed and prints the address. In ThreeRT for macOS, Studio has a Publish button that does the same.
    
        
    $ threert login
$ threert publish
    3. 
      
  3. Share the address
    The first publish claims the name, first come, first served. Its address is the app’s page and the link ThreeRT opens. A game that uses @threert/net gets multiplayer rooms, and anyone can start their own project from yours with threert remix.
    
        
    https://your-app.threert.app
