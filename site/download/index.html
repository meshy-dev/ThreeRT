Scan, and it runs.

The client is a runtime, not one game. Like Expo Go for an app, it loads whatever project you point it at, and it loads it again every time you save.

  1. Run threert dev

    It bundles your game on every save, serves it on your network and prints a QR code.

  2. Scan the code

    With ThreeRT on the iPhone. On the Mac that runs the dev server, ThreeRT for macOS opens the game by itself.

  3. Traced, and live

    The same code is path-traced on the device. Save a change and every connected client reloads. The game’s logs print in your terminal.

$ threert dev

A link is all a game needs

The code carries threert:// and the dev server’s address. This one holds the example address from the terminal output; yours has your machine’s.

No ray tracing? Still the same game.

A device the client cannot trace on, and every browser, opens the same game as three.js: the dev server and every published package serve that page next to the code. See it on the apps at threert.app.
