On your own GPU.

ThreeRT games are code. The client fetches a game from a link, a dev server or a QR code and path-traces it on the device in front of you. The clients are free.

ThreeRT for macOS

macOS 14 or later · Apple silicon
  • Its Showcase is the catalogue of threert.app: the apps and games published there, traced on your Mac
  • Opens games from threert:// links, from dev servers on your network and from its own library of examples
  • Hardware ray tracing on M3 and later; dynamic resolution holds the frame rate
  • A game plays as soon as it opens: drag to orbit, click to play, ⌘R to reload, ⌘S for a screenshot
  • Carries the threert command line: Install threert in its library puts it on your PATH
  • Keeps itself up to date: a new version is offered in the app as soon as it is out (Check for Updates…, or Settings for automatic installs)

ThreeRT for iPhone

iOS 17 or later · iPhone and iPad
  • Scan the QR code that threert dev or ThreeRT for macOS shows, and that game opens on the phone
  • iPhone 15 Pro and later trace with hardware ray queries; other Metal GPUs trace in compute
  • One finger orbits, two pan, a pinch zooms, a tap plays; shake to reload

Scan, and it runs.

The client is a runtime, not one game. Like Expo Go for an app, it loads whatever project you point it at, and it loads it again every time you save.

  1. Run threert dev

    It bundles your game on every save, serves it on your network and prints a QR code.

  2. Scan the code

    With ThreeRT on the iPhone. On the Mac that runs the dev server, ThreeRT for macOS opens the game by itself.

  3. Traced, and live

    The same code is path-traced on the device. Save a change and every connected client reloads. The game’s logs print in your terminal.

$ threert dev

A link is all a game needs

The code carries threert:// and the dev server’s address. This one holds the example address from the terminal output; yours has your machine’s.

No ray tracing? Still the same game.

A device the client cannot trace on, and every browser, opens the same game as three.js: the dev server and every published package serve that page next to the code. See it on the apps at threert.app.
